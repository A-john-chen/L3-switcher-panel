# L3-switcher-panel.
Bitfocus Companion Universal Switcher Panel,Compatible with L3 Switcher.
Compatible Device: Feelworld L3 Series Switcher;
Function Introduction:Signal switching, PIP, KEY, media playback, recording, stream start/stop and other functions.

plaintext
1. Download the .companionconfig file
2. In Companion, go to Settings → Import / Export
3. Select the file to import and check the items as needed
4. Go to the Instances page and change the device IP to your actual device address

   Notes: You need to configure the device network by yourself. The device IP in this file is set to the default value; please modify it according to your actual situation.
